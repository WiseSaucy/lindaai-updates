# Linda BizOps — Master Operator Dashboard

## Overview

This is the flagship view of the Operator Pack. One command pulls a complete operations snapshot from every other skill in the pack: cash position, 13-week forecast headline, AR/AP aging totals, payroll due this week, compliance items in the next 30 days, vendor renewals + underperformers, tenant pipeline + vacancies, PM status by property, this-week's critical items, and a quick-action list. The whole damn operation, on one page, every morning.

## When This Skill Applies

- "Run my BizOps dashboard"
- "Operations snapshot"
- "What's happening across the business?"
- "Daily ops pulse"
- "Operator command center"
- "Biz ops update"
- "Status across everything"

## How It Works

### Step 0: License Check
Standard LindaAI license verification.

### Step 1: Pull From Every Operator Skill

In parallel, query:

| Source | Data Pulled |
|--------|-------------|
| `linda-books` | Current cash by account, MTD revenue, MTD expenses, MTD net |
| `linda-cashops` | Week-1 to Week-13 closing cash, any amber/red alerts |
| `linda-cashops` (AR) | Total outstanding, total > 60 days |
| `linda-cashops` (AP) | Total payable, total overdue |
| `linda-payroll` | Pay runs due this week, contractors missing W-9 |
| `linda-compliance` | Items due in next 30 days, anything overdue |
| `linda-vendor` | Vendors expiring next 90 days, performance < 3.0 |
| `linda-tenants` | Vacant units, pre-screened applicants in pipeline, applications pending |
| `linda-pmfind` | Open PM searches, pending PM proposals |
| `linda-deductions` | YTD deduction total, red-flag categories |
| `linda-files` | Docs expiring next 90 days |
| `linda-monday` | This week's Monday digest summary |
| `linda-notion` | This week's Notion calendar events |
| `linda-bgcheck` | Pending background checks |

### Step 2: Build the Dashboard

Output is a single MD page + matching PDF, structured as:

```markdown
# 🤠 Operator Dashboard — {entity or "All Entities"} — {YYYY-MM-DD}

## 💵 Money
- Cash: $XX,XXX across N accounts
- 13-week low: $XX,XXX (week N) — {green/amber/red}
- AR: $XX,XXX total · $X,XXX over 60 days
- AP: $XX,XXX total · $X,XXX overdue
- MTD Net: $X,XXX ({trend vs prior month})

## 👥 People & Pay
- Pay run due this week: $X,XXX (N contractors)
- Missing W-9s: N · Backup withholding active: N
- Open hires (hiring-screener): N

## 📋 Compliance — Next 30 Days
- {Entity} {Obligation} — {N days}
- {Entity} {Obligation} — {N days}
- Any overdue: {list or "NONE — clean"}

## 🏠 Properties & Tenants
- Units occupied: N / Total
- Vacant: N · Avg DOM {N days}
- Applications pending: N (high score: {name} {score}/100)
- PM status by property: {list}

## 🤝 Vendors
- Renewing next 90 days: N
- Underperforming (<3.0 stars): N — {names}
- Open RFQs: N

## 📁 Files
- Docs expiring next 90 days: N

## 📊 Project Boards
- Monday: {N closed} this week · {N stuck}
- Notion: {N events} this week

## 🔥 This Week's Critical 3
1. {Top item}
2. {Second}
3. {Third}

## ⚡ Quick Actions
- [ ] {Suggested action 1}
- [ ] {Suggested action 2}
- [ ] {Suggested action 3}

---
Generated by LindaAI · Built for Boss · {timestamp}
```

### Step 3: Compute "Critical 3"

Linda picks the three most important items today by ranking:
1. RED alerts (overdue compliance, negative cash week, FCRA timer expired)
2. AMBER alerts (cash < buffer, missed W-9 with payment due, BG-check past 7 days)
3. Highest-leverage opportunity (top applicant ready, RFQ savings, deductions to log before quarter close)

### Step 4: Save & Surface

- MD: `brain/operator/dashboards/{YYYY-MM-DD}-bizops.md`
- PDF: `brain/operator/dashboards/{YYYY-MM-DD}-bizops.pdf`
- Latest pointer: `brain/operator/dashboards/latest.md` (always points to most recent)

If Boss is on `/saddle-up` (morning briefing), the dashboard headline (Critical 3) folds in automatically.

### Step 5: Voice / Quick Read

Linda speaks a 30-second summary:
"Howdy Boss! Cash sittin' at $48k across three accounts. 13-week low's $19k week 9 — green. AR's $24k, eight grand of that's over 60 days. Pay run Friday's $2,400. Compliance is clean for 30 days. Two vendors comin' up for renewal — Acme Plumbing and Comcast. One vacant unit, two strong applicants. Critical 3 today: chase the over-60 AR, Drew needs a W-9, Burlington duplex applicants need a decision. Yeeee Hawww 🤠"

## Error Handling

- **One source skill fails:** Continue with rest, note which section is missing data.
- **No data yet (fresh install):** Stub the section with "Set up {skill} first" prompt.
- **Multi-entity confusion:** If two entities share a vendor / contractor, attribute by majority spend.
- **No license:** Country howdy and stop.
