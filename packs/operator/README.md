## Cross-skill superpowers

The Operator Pack's real magic is in the chains. Skills feed each other so the operator types one command and a whole workflow fires:

- **Receipt → Tax Package** — Photo a receipt → `linda-deductions` categorizes → tallies by IRS category → `linda-taxprep` pulls them all into year-end CPA package.
- **Books → Cash Forecast → Dashboard** — `linda-books` posts ledger → `linda-cashops` builds 13-week forecast → `linda-bizops` surfaces low-cash alerts on the dashboard.
- **Tenant → BG Check → Lease → Files** — `linda-tenants` scores applicants → top score gets `linda-bgcheck` invite → on approve, lease drafted → `linda-files` cabinets the executed lease.
- **Vendor → 1099 → CPA** — `linda-vendor` flags 1099-eligible vendors → `linda-payroll` collects W-9s and runs payments → `linda-taxprep` builds 1099-NEC summaries at year-end.
- **Compliance → Calendar → Cash** — `linda-compliance` finds upcoming filings → due dates land on `linda-bizops` dashboard + filing fees flow into `linda-cashops` forecast.
- **Monday + Notion → BizOps** — Both project boards' weekly digests roll up into the `linda-bizops` "this week's critical 3" list.
